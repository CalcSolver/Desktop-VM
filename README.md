# FreeDOS WebAssembly Virtual Machine

A completely static, client-side virtual machine running FreeDOS directly inside any modern web browser using WebAssembly (`v86`). Hosted for free using GitHub Pages.

## 🚀 Features
* **Zero Backend:** Runs 100% in the browser client using WebAssembly.
* **No Installation:** Users can access the virtual machine instantly via URL.
* **Free & Open Source:** Powered by `v86` and FreeDOS 1.4.
